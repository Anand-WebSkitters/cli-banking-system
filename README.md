# Banking System - CLI


### Some Git Commands

- `git init` Initialize a git repo
- `git add .` Stage all changes
- `git commit -m "commit message"` commit all the staged changes
- `git push origin BRANCH` push changes to the remote repo
- `git fetch origin` to fetch all the changes from the remote repo.
- `git status` to check the status of our local repo.
- `git checkout -b BRANCH_NAME` to create and switch to a branch
- `git checkout BRANCH_NAME` to switch to a branch
- `git pull origin BRANCH` to pull changes from origin branch
